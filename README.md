# AI 交易智耕農官網 v1（內容充實版 v1.5，2026-10-22）

一頁式靜態官網（繁體中文），純 HTML/CSS/JS，無建置步驟，可直接部署 Cloudflare Pages。

## 內容（九段）

1. Hero：品牌＋三個 CTA（安裝擴充／八步法拆解／訂閱頻道）
2. 免費工具 `#tool`：隔夜套利八步評分（文案取自 Chrome Web Store 上架文案）＋八步門檻＋實測截圖＋台北時間進場窗口標示
3. 八步法完整拆解 `#method`：交易閉環（尾盤進場／過夜／早盤出場）＋鐵律＋八步逐條「在防什麼」
4. 回測實驗室 `#lab`：AI 5 策略健檢數據故事（獲利集中度、統一條件重測）＋3 個自保技巧
5. 教學影片 `#video`：最新影片嵌入（CvhL8gq4hvk）＋影片庫（2 支主片卡片）
6. 尾盤掃描日報 `#daily`：最新一期（2026-10-22，結論圖卡＋摘要）＋歷期歸檔列表
7. 免費指標領取 `#indicators`：3 支 invite-only 指標介紹＋領取三步驟（表單直連待 Sean 提供 3 個 Google 表單連結後換上）
8. FAQ `#faq`：6 題（費用／適用股票／評分意義／收盤資料／指標領取／日報更新）
9. 關於／追蹤＋免責聲明

v1 不放 Lemon Squeezy 購買按鈕：等商店 Stripe 身分驗證有結果再加。

## 部署（Cloudflare Pages，約 2 分鐘，需 Sean 本人）

1. 到 cloudflare.com 註冊免費帳號
2. 把本資料夾推上 GitHub repo 後，在 Cloudflare Pages 連接該 repo（無建置指令、輸出目錄填根目錄 `/`），或直接用 Wrangler 上傳本資料夾
3. 先用 `*.pages.dev` 子網域上線；自有網域之後再綁
